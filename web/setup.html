Configurar este dispositivo para XtendedView

El visor necesita HTTPS para decodificar vídeo con el navegador. El portátil usa su propio certificado, así que hay que confiar en él una vez por dispositivo.

Opción rápida (Chrome en Android, para probar)

  1. Abre la pantalla por HTTPS.
  2. Chrome avisará de que la conexión no es privada: toca Configuración avanzada y después Acceder a … (sitio no seguro).
  3. Introduce el código que aparece en el panel del ordenador y pulsa Conectar.

Tendrás que aceptar el aviso de nuevo de vez en cuando. Para dejarlo resuelto, instala el certificado.

Instalar el certificado (recomendado, una sola vez)

Descargar certificado

Android (Samsung Galaxy):

  1. Ajustes → Seguridad y privacidad → Más ajustes de seguridad → Instalar desde almacenamiento del dispositivo → Certificado de CA.
  2. Acepta el aviso y elige xtendedview-ca.crt en Descargas.

iPad / iPhone (Safari):

  1. Al descargarlo, permite la descarga del perfil.
  2. Ajustes → Perfil descargado → Instalar.
  3. Ajustes → General → Información → Ajustes de confianza de certificados → actívalo.

Aparecerá como «XtendedView - CA local …». Solo vale para direcciones privadas (las de tu red local), no para ninguna web de internet. Comprueba que la huella coincide con la del ordenador:

Quitar un certificado

Si ya no usas XtendedView en ese ordenador, o tienes uno suyo que ya no sirve (por ejemplo, tras reinstalarlo), bórralo: aparece como «XtendedView - CA local …».

  • Android: Ajustes → Seguridad y privacidad → Más ajustes de seguridad → Ver certificados de seguridad → pestaña Usuario → tócalo → Eliminar.
  • iPad / iPhone: Ajustes → General → VPN y gestión de dispositivos → el perfil → Eliminar perfil.

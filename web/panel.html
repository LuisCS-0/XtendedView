¿Primera vez con este dispositivo?

El navegador avisará de que la conexión no es privada: toca Configuración avanzada → Acceder. Para no volver a verlo, instala el certificado del ordenador desde :

  • Android: Ajustes → Seguridad → Más ajustes de seguridad → Instalar desde almacenamiento → Certificado de CA.
  • iPad / iPhone: Ajustes → Perfil descargado → Instalar; después General → Información → Ajustes de confianza de certificados.

Si el dispositivo tenía el certificado de una versión anterior («Pantalla PoC CA…»), bórralo: la página de instalación explica cómo.

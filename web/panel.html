Conectando con el host…

¿Cómo quieres conectar el dispositivo?

Elige una opción para empezar. Podrás cambiarla después desde el panel.

Conexiones

La Wi-Fi o la red a la que ya está conectado este ordenador.

El ordenador crea su propia Wi-Fi, sin router ni internet.

Android con módem USB: la mínima latencia y sin depender de ninguna red.

Esperando el cable…

  1. Conecta el móvil al ordenador con un cable USB que sirva para datos (no solo para cargar).
  2. En el móvil, activa el módem USB: Ajustes → Conexiones → Conexión compartida y Módem → Módem USB (en otros Android, «Compartir conexión por USB» o «Anclaje de USB»).
  3. En cuanto el ordenador lo detecte, aquí aparecerá el código QR para abrir la pantalla.

iPad u otro ordenador: también sirve un adaptador USB-C a Ethernet con un cable de red directo a este ordenador.

Hay un móvil conectado por cable (). Por cable tendrás menos latencia y sin tirones.

¿Primera vez con este dispositivo?

El navegador avisará de que la conexión no es privada: toca Configuración avanzada → Acceder. Para no volver a verlo, instala el certificado del ordenador desde :

  • Android: Ajustes → Seguridad → Más ajustes de seguridad → Instalar desde almacenamiento → Certificado de CA.
  • iPad / iPhone: Ajustes → Perfil descargado → Instalar; después General → Información → Ajustes de confianza de certificados.

Si el dispositivo tenía el certificado de una versión anterior («Pantalla PoC CA…» o «Pantalla secundaria - CA local…»), bórralo: la página de instalación explica cómo.
